# 台中看房地圖

記錄台中預售、新成屋、591 參考物件，以及學區、學校、公廟、百貨、醫院、交流道等生活機能的個人地圖。

## 開啟方式

直接雙擊 `index.html` 即可（需要網路載入底圖）。網址列會記住目前位置與縮放，例如 `#14/24.137/120.686`，可以存成書籤。

## 面板操作

- 分區：切換「行政區／重劃區／兩者」。重劃區分公辦市地重劃、自辦市地重劃、區段徵收、農地重劃、農村社區，後兩類預設關閉。
- 每個類別平常只顯示一列（開關、圖例、數量），點類別列展開名稱清單。
- 清單中滑過名稱，地圖上對應的道路、捷運線、行政區或重劃區會以橘紅色標示；點一下名稱地圖會移到該處並保持標示，點地圖任意處取消。

| 12 起 | 小路（底圖）、未來捷運車站圓點 |

左下角狀態列會顯示目前縮放值，要調整哪一層的內容時可以直接說「縮放 13 的時候……」。

## 重新產生資料

```bash
PYTHONPATH=tools/pylib python3 -W ignore tools/route_future.py   # 未來捷運線形與車站
PYTHONPATH=tools/pylib python3 -W ignore tools/build_data.py     # 產生 data/*.js
```

原始資料在 `tools/raw/`；`tools/raw/fetch.sh` 可重新從 OpenStreetMap 下載。
